## Research use tracking

For every item actually used in an experiment, add a separate record to the experiment's source manifest with:
- Stable source ID and exact title/authors/year.
- DOI or official URL and date accessed.
- Dataset/paper version and license/access conditions.
- Whether abstract, full text, or selected sections were inspected.
- Local evidence location identifiers (do not commit copyrighted full text unless redistribution is permitted).

Current repository metadata alone does not establish that any of these five papers was used as a source in the current experiment.
