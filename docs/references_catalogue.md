## Research-use tracking

For every item actually used in an experiment, add a separate record to the experiment's source manifest with stable source ID, exact metadata, DOI/official URL, access date, source version/license, inspected scope, and evidence location identifiers. A PDF being present in the repository does not establish that it was used as experimental evidence.
