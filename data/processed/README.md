# Processed data and annotation templates

- `sample_claim_evidence.jsonl` contains synthetic software-test examples only. It is not a scientific dataset.
- `schema.json` defines the root claim/evidence record format.
- `annotation_template.csv` is an empty header template for claim-level annotation.

Store only permitted, documented records here. Keep restricted raw corpora and private annotations out of version control unless release terms explicitly allow redistribution. See [research data management](../../docs/research_data_management.md).
