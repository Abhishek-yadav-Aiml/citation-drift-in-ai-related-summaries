# Changelog

All notable repository changes are documented here.

## 0.1.0 — 2026-11-18
- Added a root TF-IDF cosine-similarity review baseline and CLI.
- Added JSONL validation and explicit exclusion of unavailable evidence from similarity scoring.
- Added a separate AlignScore scaffold with a BM25 helper, score export and guarded development-partition binary evaluation.
- Added annotation policy, data dictionary, schema, research protocol and bibliography catalogue.
- Added IEEE LaTeX source and BibTeX references, then committed the compiled IEEE PDF.
- Added three unmodified ACL Anthology source-paper PDFs with per-paper reuse notes and checksums.
- Added official links for the two DeBERTa papers, which are not mirrored because their broader redistribution licenses were not confirmed.
- Added GitHub Actions test and PDF publication workflows.
- Added synthetic smoke-test data; no real research dataset or model checkpoint is bundled.
